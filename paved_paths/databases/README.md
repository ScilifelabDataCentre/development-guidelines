# Databases

> [!TIP]
> **Quick guidance**
>
> - In-memory: Use Redis when you need persistence, pub/sub/streams, Lua, or clustering; use Memcached for simple ephemeral cache-only.
> - Time-series: Prometheus is for observability/metrics. For analytics/joins/SQL on time-series use TimescaleDB ⚠️ or ClickHouse; consider InfluxDB ⚠️ for high-resolution metrics.
> - Graph: Neo4j Community lacks clustering and some enterprise features; pick JanusGraph for distributed graphs on commodity backends.
> - Documents: Prefer PostgreSQL + JSONB by default; for multi-model, consider ArangoDB. Couchbase CE ⚠️ is source-available and feature-limited.

> [!NOTE]
> **Licensing**
>
> - “Open source” refers to OSI-approved licenses. SSPL is source-available and not OSI-approved.
> - "⚠️" indicates tools with non-permissive licenses, commercial editions, or source-available terms (e.g., Couchbase Community Edition, Neo4j Community Edition, TimescaleDB, MongoDB, InfluxDB).
