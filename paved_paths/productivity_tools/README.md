# Productivity tools

Tools often used by developers, but not strictly development tools.

| Purpose                           | Default Tool                                   | Why?                                                                                                                                                                                                                                                                                      | Alternatives                                                                                                                                                   |
| --------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project management/issue tracking | [Jira](https://scilifelab.atlassian.net/jira/) | [See explanation](./why_jira.md)                                                                                                                                                                                                                                                          | [GitHub Issues](https://github.com/features/issues)                                                                                                            |
| Diagramming                       | [Mermaid](https://mermaid.js.org/)             | Great for simple diagrams (and simple diagrams are often great!), define diagrams declaratively, supported in [GitHub Markdown](https://github.blog/developer-skills/github/include-diagrams-markdown-files-mermaid/) and [pandoc](https://github.com/raghur/mermaid-filter), open source | Use [DrawIO](https://github.com/jgraph/drawio-desktop) if you need more complexity/flexibility; has online and desktop versions, SVG export and is open source |
| UI/UX prototyping                 | [Figma](https://www.figma.com/)                | Dominant tool in the market, easy collaboration, not open source but we can use [the educational plan](https://www.figma.com/education/)                                                                                                                                                  | https://github.com/penpot/penpot is open source but would require us to self-host an instance                                                                  |
