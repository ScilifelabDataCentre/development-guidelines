# Linting & static analysis

The following linting tools are best used in combination with IDE plugins, git hooks, e.g. via [pre-commit](https://pre-commit.com/) or [husky](https://typicode.github.io/husky/) and with CI/CD pipelines.

| Purpose                 | Default Tool                                                                       | Why?                                                                      | Alternatives                                                                                                                                                  |
| ----------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| General code formatting | [Prettier](https://prettier.io)                                                    | Widely adopted, opinionated, supports many languages                      | - [Biome](https://biomejs.dev/): rust-based, but fewer languages supported <br> - [dprint](https://dprint.dev/): rust-based, opt-in approach to add languages |
| Python linting          | [ruff](https://docs.astral.sh/ruff/)                                               | Rust-based, faster successor to Black, isort and Flake8                   |                                                                                                                                                               |
| Javascript linting      | [ESLint](https://eslint.org/)                                                      | Widely adopted, highly configurable, catches bugs and enforces code style | [Prettier](https://prettier.io): if you only need code formatting                                                                                             |
| Markdown linting        | [Prettier](https://prettier.io)                                                    |                                                                           | [mdlint](https://github.com/Laboratoria/mdlint)                                                                                                               |
| HTML linting            | [Prettier](https://prettier.io)                                                    |                                                                           |                                                                                                                                                               |
| Ruby linting            | [rubocop](https://rubocop.org/)                                                    |                                                                           |                                                                                                                                                               |
| Shell linting           | [ShellCheck](https://www.shellcheck.net/)                                          |                                                                           |                                                                                                                                                               |
| Typescript linting      | [ESLint](https://eslint.org/) + [TypeScript ESLint](https://typescript-eslint.io/) | Widely adopted, highly configurable, catches bugs and enforces code style | [Prettier](https://prettier.io): if you only need code formatting                                                                                             |
| Dockerfile linting      | [hadolint](https://github.com/hadolint/hadolint)                                   |                                                                           |                                                                                                                                                               |
| Accessibility           | [WAVE](https://wave.webaim.org/)                                                   |                                                                           |                                                                                                                                                               |
