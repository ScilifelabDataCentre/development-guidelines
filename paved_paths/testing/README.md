# Testing

| Purpose                     | Default Tool                                                            | Why?                                                                                                                                                                                                                                                                                                                      | Alternatives                                                                                                                                                                                                                                               |
| --------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Web application E2E testing | [Cypress](https://docs.cypress.io/)                                     | Modern, open source, simple, widely used, large community, CI. Native support of the async nature of the web with built-in wait mechanisms and automatic retries. Tests run fast in the browser. Support for component tests. Video and screenshot recordings.                                                            | [Playwright](https://playwright.dev/): consider using if mobile testing is important or if more browsers need to be tested. Also if developers prefer to write tests in a language other than js.                                                          |
| Python unit testing         | [pytest](https://docs.pytest.org)                                       | Large community, light weight, simple and concise syntax. Supports Python’s unittest tests. Method decorators, fixtures, test discovery. Many plugins. Supports parallel tests. Nice test result output.                                                                                                                  |                                                                                                                                                                                                                                                            |
| Test Coverage               | [pytest-cov](https://github.com/pytest-dev/pytest-cov) with coverage.py | Python-based. Integrates with pytest and CI/CD. Open source. Can generate reports in html, json, etc.                                                                                                                                                                                                                     | [Codecov](https://about.codecov.io/): consider for more features.                                                                                                                                                                                          |
| API testing                 | [pytest](https://docs.pytest.org) with requests                         | Python is our default language. Developers will find it flexible and powerful. Integrates very well with CI/CD. Open source. Already installed and in use as the unit test tool (fewer tools to maintain).                                                                                                                | [Postman](https://www.postman.com): consider using for systems that are heavily reliant on API design (API first). Locust should be used to load test the API suite if the API is deployed on the same infrastructure as the main SUT (System Under Test). |
| Load testing                | [Locust](https://locust.io/)                                            | Modern, powerful, flexible, large community, open source. Tests are written in Python, our default language, so appeals to most developers and makes the tests very flexible. Basically you can do anything that Python can do. No need to learn a new configuration syntax. Native support for distributed load testing. | Applications that rely on JavaScript for a large portion of the work can consider also testing the client browser load.                                                                                                                                    |
| Container testing           | [Trivy](https://trivy.dev/)                                             | Easy to use, widely used, large community, actively maintained, can use in CI, open source.                                                                                                                                                                                                                               |                                                                                                                                                                                                                                                            |
