# Desktop application development

The following tools assume the use of _Python_, in line with it being the main general purpose language. However, if you are creating a computationally intensive desktop application, you may need to reconsider this.

| Purpose                          | Default Tool                                               | Why?                                                                                                                                                                                                                                                                                         | Alternatives                                                                                               |
| -------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| CLI (Command Line Interface)     | [Typer](https://github.com/fastapi/typer)                  | Widely used, open source, [facilitates testing](https://typer.tiangolo.com/tutorial/testing), uses FastAPI paradigms                                                                                                                                                                         | [Click](https://github.com/pallets/click) - Typer is based on this, DC's only existing desktop app uses it |
| GUI (Graphical User Interface)   | [PyQt5](https://www.riverbankcomputing.com/software/pyqt/) | Drag-and-drop interface (QtCreator) to quickly create interfaces, supports Mac/Windows/Linux, licensed under [GPL license](https://en.wikipedia.org/wiki/GNU_General_Public_License) which is typically OK for us as an open source organisation. Note that commercial Qt licensing differs. | Prefer [Kivy](https://github.com/kivy/kivy) for mobile and touch screen apps                               |
| Distributables/installers        | [PyInstaller](https://pyinstaller.org/en/stable/)          | Most widely used, supports Mac/Windows/Linux, almost all requirements can be met (with some configuration)                                                                                                                                                                                   |                                                                                                            |
| TUI (Text-based User Interface)^ | [Textual](https://textual.textualize.io/)                  | Open source, widely used, used by [nf-core](https://nf-co.re/docs/nf-core-tools/cli/tui)                                                                                                                                                                                                     |                                                                                                            |

^Technically, a CLI is a type of TUI. With a CLI you are only ever interacting via typed commands, whilst a TUI
is a customised text-based interface which can take hotkeys and mouse inputs, hence why we have different paved path
tools.
