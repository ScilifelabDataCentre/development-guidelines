# Proposal process

This is both a process and a document template.

## When do you use this process/template?

_Before_ substantial work begins on a project or new service.

| ![](images/blurry_lightbulb.png "Blurry cartoon of a lightbulb") | ![](images/clear_lightbulb.png "Clear cartoon of a lightbulb") |
| :--------------------------------------------------------------: | :------------------------------------------------------------: |
|                      A hazy, undefined idea                      |                  Clear description of an idea                  |

## Why?

- Create shared picture of the high-level vision
- Ensure we have a 'why' (product justification/positioning statement)
- Get sign-off on investment of further time and resources
- Document that sign-off

1. An idea (e.g. proposal from a researcher, discussed in a meeting), which is likely vague
2. Do just enough research to write the proposal
3. Write the proposal (using a copy of the [template](.)) and place it in the `In Review` folder
4. [DCMG](glossary.md#dcmg-) reviews it
5. Decision: signed off or not. Place it in the `Approved` or `Will Not Proceed` folder

> [!NOTE]  
> Steps 3-4 are an iterative loop with feedback and changes.

## Tips

> [!TIP]
> Most important: Keep it short! If your proposal is >2 pages, it may contain unnecessary information.
> The reader should be able to read it quickly and get an understanding of what problem you're trying to solve and a
> very high-level description of the solution.

- The 'positioning statement' in the _Summary_ section is critical - if we don't have a specific, unmet need we are
  trying to solve then we probably should not invest more resources.
- Consider whether a new project or service needs to exist - can the unmet need be fulfilled as part of an existing
  service?
- Refresh your understanding of [RACI roles](raci.md).
- This is not a living document (i.e. you won't go back and update this once work has begun). However,
  if the project or service changes so dramatically that the high-level document no longer describes it, maybe it
  should have a new proposal.
